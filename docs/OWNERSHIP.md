What this repository is made of, path by path. The "mine" column is the one that
matters: it asks whether *I* can rebuild the file from memory, without reading it.
An agent's guess at that is worthless, so the column is left unticked on purpose —
it is a weekly self-check, not a documentation task. Ticking it honestly is the
difference between owning this project and having assembled it.

Legend: **original** = written for this repository; **port** = rewritten from an
upstream design in another language; **vendored** = upstream files, unmodified;
**generated** = produced by a command in this repository.

## The question this table is really asking

A file is "mine" when I can delete it, rewrite it, and have the tests still pass —
because I know what it must do, not because I remember what it said. The two rows in
this table that are not mine (`c/microgpt.c`, `reference/**`) are the two that must
never be edited in place: they are the fixed point the rest is checked against.
