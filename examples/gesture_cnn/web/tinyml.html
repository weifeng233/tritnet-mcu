任务 GESTURE RECOGNITION

这是 TinyML 社区最经典的传感器任务之一（EdgeImpulse / MLPerf-Tiny 风格）：对一段 3 轴加速度计时间窗做 4 分类。数据由 examples/gesture_cnn.zig 内置的确定性生成器合成，每个类别带随机相位、幅度抖动与逐样本噪声，因此整条管线从固定种子完全可复现，无需外部数据集。

四类手势的合成波形

网络必须学波形形状，而不是背样本——每类都有随机相位和幅度抖动，噪声叠加在所有轴上。
rest（静息）

三轴缓慢低幅漂移，每窗 <0.3 周期，振幅 0.22。

shake（摇晃）

集中于 x 轴的快速震荡，每窗 8–12 周期，振幅 1.0±0.2。

circle（画圈）

x/y 正交对，每窗 2–4 周期，z 轴安静。

tap（轻敲）

随机位置、随机轴上的衰减脉冲（宽度 14–21），振幅 1.4–2.2 带随机符号。

数据集可复现：类标签按 idx % 4 轮转填入，再做一次 Fisher-Yates 洗牌，使验证集类别混合均匀。噪声标准差 0.06。

网络架构 2,524 PARAMS · 54,208 MACs

典型的 TinyML 短 1D-CNN：两层卷积（每层接 ReLU + 步长 2 最大池化）后接全连接分类头。所有卷积核与稠密层都量化成 {-1, 0, +1} 三元权重，偏置保持 fp32（共 28 个，占比极小——专门用来吸收三元网格表达不了的东西）。

三元量化 BITNET · QAT

量化语义与仓库里的 micro-GPT 管线完全一致：先做 fp32 预训练，随后用 absmean 缩放把每个投影张量化为三元，再用 直通估计（STE）做量化感知训练（QAT）把精度补回来。每个卷积核与稠密层按张量独立得一个缩放因子，激活在训练时量化到 8-bit。

BitNet 三值化规则

项取值
缩放因子scale = mean(|W|)，即权重绝对值的均值
阈值t = scale / 2
三值映射W > t → +1 · W < -t → -1 · 其余 → 0
部署值q = trit × scale
梯度掩码（STE）只在 |W| < 2t 处保留梯度，别处置 0
激活量化训练时 per-token 8-bit（舍入后 STE 反向为恒等）
为什么偏置保持 fp32：三元网格只能表达 ±scale 和 0 三种值，偏置的作用就是吸收常数偏移——把它们也量化成三元，会凭空引入误差且几乎没有压缩收益（28 个参数 vs 2496 个权重）。

训练管线 FP32 PRETRAIN → TERNARY QAT

单进程内依次执行：fp32 预训练（Adam + 余弦学习率，mini-batch 交叉熵，批量 32）→ 记录 朴素 PTQ（直接三值化、不做 QAT）作为对照 → 重置 Adam → BitNet 三元 QAT。下方损失曲线把两段画在一起（x 轴为累计步数，y 轴为对数刻度）。注意 QAT 第 1 步的 loss 从 fp32 收敛态的 0.002 直接跳回 15.66——这就是三值化冲击本身，QAT 随后用 1500 步把它重新压回去。

存储与延迟 PACKED · 5 TRITS/BYTE

三值权重用 5 个三值位/字节的基-3 打包（compilade 的方案，llama.cpp 的 BitNet 也用这套）：编码时对基-3 权重做天花板重缩放，解码时用乘法+移位、免除法。打包后权重从 10,096 字节压到 672 字节，15.0x 小于 fp32。

注意：这是主机 CPU 上跑 float 激活的参考延迟——x86 上 fp32 靠 AVX2 FMA，查表乘加被优化得很好，三元核只是基本持平（38.00 vs 38.77 µs，2% 差异在运行间噪声内），并没有因为量化而变快。真正的收益是把权重从 10KB 压到 672B（对缓存 / 片上存储 / 指令流都是质变），以及三值核可用「加/跳过/减」的加法替代乘法。在真正的 MCU 上，三元核的免乘法优势才会体现为吞吐优势。

构建与运行 BUILD

一条命令跑完整个管线

$ zig build --release=fast cnn
→ 训练 → 量化 → 验证 → 导出模型+验证集
$ ./zig-out/bin/example-cnn.exe
→ examples/gesture_cnn/modeldata/cnn1d_packed.bin（672 B）
→ examples/gesture_cnn/modeldata/cnn1d_valset.bin（验证集）
$ zig build test # 卷积/池化/梯度/端到端梯度检查 单元测试

双部署路径

除了 Zig 主管线，仓库还提供 examples/gesture_cnn/c/cnn1d_inference.c 作为独立的部署引擎：它读取 examples/gesture_cnn/modeldata/cnn1d_packed.bin 与验证集，解码打包 trits 后以 add / skip / subtract 方式跑三元核——不用任何逐权重浮点表。两条路径必须逐点复现相同的验证精度与混淆矩阵。

$ make cnn-c
$ ./examples/gesture_cnn/cnn1d-c examples/gesture_cnn/modeldata/cnn1d_packed.bin examples/gesture_cnn/modeldata/cnn1d_valset.bin
